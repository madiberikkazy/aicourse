Ақпарат

Неліктен AI Vibecoding?

Vibecoding — бұл жасанды интеллектпен бірге ойлап, бірге жазатын жаңа буын бағдарламалау тәсілі.

Практикалық үйрену

Теориядан емес, тікелей жобадан бастаймыз. Балалар бірінші сабақтан бастап нақты нәрселер жасайды.

Жасанды интеллект күші

ChatGPT, Claude сияқты AI құралдарын пайдаланып, бағдарламалауды жеңіл және қызықты ету.

Шығармашылық ойлау

Техникалық дағдылармен қатар, балалардың шығармашылық және сыни ойлауын дамытамыз.

Жол картасы

Нәтижеге апарар Жол

Нөлден бастап өзіңіздің AI қосымшаңызды жасауға дейін — кезең-кезеңімен.

01

Интернет, компьютер және бағдарламалаудың не екенін түсіну. AI-мен алғашқы сөйлесу.

  • HTML & CSS негіздері
  • ChatGPT пен жұмыс
  • Алғашқы веб-бет

Бұл кезеңде бала интернеттің қалай жұмыс істейтінін, браузер мен серверлердің байланысын түсінеді. Алғашқы HTML тегтерін жазып, өз атынан жасалған қарапайым веб-бетті шығарады. Сабақ соңында әр оқушы ChatGPT-пен диалог құрып, қарапайым сұрақтарға жауап алуды үйренеді.

02

Cursor IDE-мен таныстыру. AI-ға тапсырма беру және код жаздыру.

  • Cursor орнату
  • Промпт жазу өнері
  • Алғашқы JS қосымша

Оқушылар Cursor IDE-ні өз компьютерлеріне орнатып, алғашқы AI-көмегімен жазылған қолданбаны құрастырады. Промпт жазу дағдысы дамиды: нақты тапсырма қалай тұжырымдалады, AI-дан қандай нәтиже күтуге болатынын үйренеді. Модуль соңында әр бала JavaScript-те жұмыс істейтін шағын интерактивті виджет жасайды.

03

Midjourney арқылы AI суреттер жасау, сайттарды әдемі ету.

  • Figma негіздері
  • Midjourney промпттары
  • Адаптивті дизайн

Figma-да фреймдер мен компоненттермен жұмыс істеу үйретіледі, ал Midjourney арқылы бала өз жобасына арналған иллюстрациялар мен иконкалар жасайды. Түстер палитрасы, типографика және композиция негіздері беріледі. Нәтижесінде әр оқушы өз сайтының толық дизайн-макетін дайындайды.

04

Node.js және Gemini API пайдаланып, деректермен жұмыс жасайтын қосымша жасау.

  • API дегеніміз не?
  • Gemini API интеграция
  • Дерекқор негіздері

Node.js көмегімен сервер жағының қалай жұмыс істейтінін түсінеді, ал Gemini API интеграциясы арқылы AI жауап беретін чат-бот немесе көмекші құрады. JSON форматымен, fetch сұраныстарымен және async/await синтаксисімен танысады. Бұл кезең — бала алғаш рет клиент пен сервер арасындағы толық байланысты өз көзімен көреді.

05

Бастан аяқ өзіндік AI қосымшасын жасау және интернетке орналастыру.

  • Full-stack жоба
  • Deployment (Vercel)
  • Портфолио

Оқушы идеядан бастап дайын өнімге дейінгі жолды толық өз бетінше өтеді: жобаны жоспарлау, интерфейс салу, backend қосу және Vercel платформасына жүктеу. Тьюторлар жеке кеңес беріп, кодты тексереді. Курс соңында әр бала портфолиосына қосатын жұмыс істейтін AI қосымшасымен шығады.
